## 📌 О проекте

**ESGML (Everlasting Summer Git Mods Loader)** — это открытый менеджер модификаций и децентрализованный загрузчик контента для визуальной новеллы **«Бесконечное лето»** (Everlasting Summer).

Исторически моды для «Бесконечного лета» распространялись через Мастерскую Steam (Steam Workshop). Однако со временем многие знаковые работы удаляются авторами, блокируются модерацией или страдают из-за поломки ссылок. **ESGML решает эту проблему раз и навсегда**: он позволяет скачивать, устанавливать, пакетно обновлять и удалять модификации напрямую из независимых источников — **GitHub, GitLab, Internet Archive (archive.org)** или любых кастомных веб-серверов.

## ✨ Ключевые возможности ESGML v4.1

* **Независимость от Мастерской Steam**: Загрузка модов напрямую по защищённым протоколам HTTP/HTTPS в формате `.rpa` и `.rpyc`.
* **Удобный оверлей в главном меню**: Доступ к каталогу модов в 1 клик прямо из стартового экрана игры (кнопки «Моды» и «ESGML»). При желании оверлей отключается в меню «Настройки и отладка».
* **Пакетные очереди загрузки и удаления**: Выбирайте сразу несколько модов кнопкой `+ В очередь` и скачивайте/удаляйте их одной операцией с прогресс-баром и процентами.
* **Кастомные пользовательские репозитории (`repos/`)**: Добавление собственных каталогов модов без модификации кода загрузчика! Достаточно положить `.rpy` или `.json` файл в папку `repos/`.
* **Фоновое кэширование скриншотов**: Превью модов подгружаются по прямым веб-ссылкам в отдельном потоке и кэшируются на диск — интерфейс остаётся плавным и отзывчивым.
* **Отказоустойчивость сети**: Таймаут соединения 60 секунд, интеллектуальный механизм автоповтора (до 3 попыток при сбоях связи), атомарная запись файлов `.part` и защита интерфейса Ren'Py от вылетов при ошибках.
* **Автономный инструментарий ESGML SDK**: Комплект Python-утилит без внешних зависимостей для сборки, тестирования, проверки статуса в Steam и заливки на Internet Archive.

## 🛠 Создание собственного репозитория

Для подключения собственных модов в ESGML **не нужно** редактировать внутренности мода. Просто создайте файл в папке `repos/`.

### Рекомендуемый способ: Нативный `.rpy` (надёжно)
Создайте файл `repos/my_repo.rpy`:

```renpy
# -*- coding: utf-8 -*-
init 5 python:
    git_easyrepo(
        'my_mod_id',
        (
            "https://archive.org/download/my_item/git_my_mod_base.rpyc",
            "https://archive.org/download/my_item/git_my_mod_res.rpa"
        ),
        'Название моего крутого мода',
        u'''Подробное описание сюжета, список концовок и авторы.''',
        scr1="https://archive.org/download/my_item/screen1.png",
        scr2="https://archive.org/download/my_item/screen2.png",
        scr3="https://archive.org/download/my_item/screen3.png"
    )
```

### Альтернативный способ: JSON (`repos/my_repo.json`)
```json
[
  {
    "id": "my_mod_id",
    "name": "Название мода",
    "links": [
      "https://archive.org/download/my_item/git_my_mod_base.rpyc",
      "https://archive.org/download/my_item/git_my_mod_res.rpa"
    ],
    "desc": "Описание мода...",
    "scr1": "https://archive.org/download/my_item/screen1.png"
  }
]
```

> 💡 Скриншоты по URL автоматически загружаются в фоновом потоке и кэшируются в `git_screens/`.

## 🧰 ESGML SDK (Zero-Dependency)

В директории `sdk/` находится полноценный SDK для авторов и архивистов. Он написан на чистом стандартном Python 3 и не требует установки сторонних пакетов:

* **`core/adapter.py`** — Интеллектуальный адаптер: автоматическая зачистка UTF-8 BOM, генерация `.rpy` скрипта загрузчика, упаковка ассетов в RPA.
* **`core/rpa.py`** — Распаковщик и сборщик RPA-архивов версий 2 и 3.
* **`core/rpyc.py`** — Инспектор заголовков и байткода `.rpyc`.
* **`core/steam_checker.py`** — Пакетная проверка статуса модов в Steam Web API (до 100 модов в пачке).
* **`core/batch.py`** — Сверка локальной коллекции модов с актуальным состоянием Steam Workshop для поиска удалённых шедевров.
* **`upload_archive_org.py`** — Загрузчик на Internet Archive через S3 API с поддержкой докачки и защиты от троттлинга.
* **`esgml_cli.py`** — Консольный интерфейс со всеми командами (`inspect`, `unpack`, `pack`, `adapt`, `check-steam`, `audit`).
* **`esgml_gui.py`** — Графический интерфейс на Tkinter с тёмной темой и пакетной обработкой.

### Сборка автономного EXE:
```bash
python sdk/build_exe.py
```
Создаст единый бинарник `dist_sdk/ESGML_SDK.exe`.

## 🤖 Адаптация модов с помощью ИИ-агентов

Для массовой адаптации старых или пропавших модов рекомендуется использовать современных ИИ-агентов (Google Antigravity, Claude Code, Cursor, Codex). 

**Типовой пайплайн работы агента:**
1. Сканирует исходную папку мода на предмет специфики Ren'Py 6 (наличие BOM `\ufeff`, устаревший синтаксис аудио).
2. Вызывает `sdk/esgml_cli.py adapt <путь_к_моду>`.
3. Запускает компиляцию `.rpy` в `.rpyc`.
4. Заливает полученный комплект на Internet Archive через `sdk/upload_archive_org.py`.
5. Генерирует готовый файл `repos/<mod_id>.rpy`.

Готовый универсальный системный промпт для ИИ доступен в [Разделе 11 ESGML_GUIDE.md](docs/ESGML_GUIDE.md#11-адаптация-модов-с-помощью-ии-агентов).
