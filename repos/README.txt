КАК ДОБАВЛЯТЬ ПОЛЬЗОВАТЕЛЬСКИЕ РЕПОЗИТОРИИ В ESGML
=====================================================

В этой папке (repos/) вы можете хранить собственные списки модов,
не изменяя оригинальный файл git_default_repo.rpy. При обновлении
загрузчика ваши добавленные репозитории никогда не пропадут!

-----------------------------------------------------
1. РЕКОМЕНДУЕМЫЙ ФОРМАТ: REN'PY (.rpy) — САМЫЙ НАДЁЖНЫЙ
-----------------------------------------------------
Скрипты .rpy выполняются движком нативно, поддерживают полный синтаксис
Ren'Py, юникод и прямые ссылки на скриншоты.

Создайте файл с любым именем, например repos/my_mods.rpy:

init 5 python:
    git_easyrepo(
        'my_mod_alias',
        ("https://archive.org/download/item_id/git_mymod_base.rpyc",
         "https://archive.org/download/item_id/git_mymod_res.rpa"),
        'Название вашего мода',
        u'''Описание сюжета, авторы и особенности модификации.''',
        scr1="https://archive.org/download/item_id/screen1.png",
        scr2="https://archive.org/download/item_id/screen2.png",
        scr3="https://archive.org/download/item_id/screen3.png"
    )

Параметры scr1, scr2, scr3 опциональны. Если указаны URL (http/https),
ESGML автоматически скачает их в кэш git_screens/ в фоне без лагов!

-----------------------------------------------------
2. АЛЬТЕРНАТИВНЫЙ ФОРМАТ: JSON (.json)
-----------------------------------------------------
Подходит, если вы хотите отдавать манифест по API или не любите писать код.
Создайте файл repos/my_mods.json:

[
  {
    "id": "my_mod_alias",
    "name": "Название вашего мода",
    "desc": "Описание сюжета...",
    "scr1": "https://archive.org/download/item_id/screen1.png",
    "scr2": "https://archive.org/download/item_id/screen2.png",
    "scr3": "https://archive.org/download/item_id/screen3.png",
    "links": [
      "https://archive.org/download/item_id/git_mymod_base.rpyc",
      "https://archive.org/download/item_id/git_mymod_res.rpa"
    ]
  }
]

-----------------------------------------------------
3. ФОРМАТ PYTHON (.py)
-----------------------------------------------------
Также поддерживаются стандартные .py файлы с вызовами git_easyrepo(...).

=====================================================
ВАЖНЫЕ ПРАВИЛА:
* Файлы с расширением .example или словом "example" в названии
  считаются шаблонами и автоматически игнорируются загрузчиком.
* Чтобы активировать репозиторий, создайте рабочий файл без "example"
  (например: repos/favorites.rpy).
* При запуске «Бесконечного лета» моды мгновенно появятся в списке ESGML!
